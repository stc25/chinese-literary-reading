## Summary

Recognising vernacular words and patterns when they appear in literary prose.

## Explanation

**Why they appear.** Literary Chinese was never sealed off from speech. Family letters, diaries,
novels' prefaces and official instructions always let in spoken words; from about 1900 the
periodical press and translation let in many more. By the 1910s a writer could choose a purely
classical style, a literary style with vernacular words, or the full vernacular. Being able to
spot vernacular elements tells you how a text positions itself.

**The commonest vernacular elements.**

| Vernacular | Function | Literary equivalent | Example |
|---|---|---|---|
| 的 de | joins modifier and noun | 之 | 雕琢的、阿諛的貴族文學 |
| 是 shì | copula "is" | ……者，……也; 乃, 為, 即 | 白話是…… |
| 是否 shìfǒu | "whether" | ……否, ……與否 | 白話果是否能達古書之義 |
| 這, 那 | "this, that" | 此, 彼, 是 | |
| 們 | plural suffix (我們, 他們) | 吾輩, 吾儕, 彼等 | |
| 他, 她 | "he, she" | 彼, 其, 之 | |
| 了 le | completed action, change of state | 矣, 已 | |
| 不要, 別 | "don't" | 勿, 毋, 莫 | |
| 沒有 | "not have, did not" | 無, 未 | |
| 甚麼, 怎麼 | "what, how" | 何, 奚, 如何 | |
| 給, 把, 被 | "give, (object marker), (passive)" | 與, 以, 為……所 | |

**Modern compound words.** Besides grammatical words, two-character modern words mark a text as
modern even when its grammar is literary: 對於 "regarding", 關於 "concerning", 類似 "similar",
因為 "because", 所以 (as "therefore" at the start of a clause), and the new terms in 形式, 內容,
問題, 主義. See [New terms](neologisms.md).

**Traps.** Some characters are both literary and vernacular, with different functions:

- 是 in literary Chinese is usually the demonstrative "this" (是以, 是故, 於是); in the vernacular it
  is the copula. 是時 "at that time" is literary; 白話是 "the vernacular is" is vernacular.
- 了 in literary Chinese is a verb, "to finish, to understand" (了本日功課 "finish the day's work",
  in [Daily study](../units/u07-time-aspect-modality/u07-p03-daily-study.md)); in the vernacular
  it marks a completed action and is read le.
- 的 dí in literary Chinese means "target, certain" (目的 "goal", 的確 "really"). Only as a
  particle after a modifier is it the vernacular de.
- 所以 in literary Chinese is "that by which, the reason"; in the vernacular it is "therefore".
  See [所以](suoyi.md).
