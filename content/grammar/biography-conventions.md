## Summary

The standard order and wording of an official biography, and how people are named in it.

## Explanation

**The fixed order.** Biographies in the official histories (正史), in gazetteers (方志) and in
epitaphs (墓誌銘) follow almost the same order. Once you know it, you can find any fact quickly.

| Part | Typical wording | Example |
|---|---|---|
| name | 某某，初名……，字……，號…… | 嚴復，初名宗光，字又陵，一字幾道 |
| native place (籍貫) | ……人 | 侯官人 |
| family (if notable) | 父……, ……之子, ……之孫 | |
| examination degree | ……年進士 / 舉人 | 光緒八年舉人 (Lin Shu) |
| character and early life | 少孤, 早慧, 嗜…… | 早慧，嗜為文 |
| career, dated | ……年，授……; 遷……; 擢……; 尋…… | 光緒二年，派赴英國…… |
| deeds, opinions | ……以為……; 嘗曰：「……」 | 復以為自由、平等、權利諸說…… |
| writings quoted | 其《……》有曰：「……」 | 其《天演論・自序》有曰 |
| reputation | 世謂……, 論者謂…… | 世謂紓以中文溝通西文 |
| death | ……年，卒，年…… | 辛酉秋，卒，年六十有九 |
| posthumous name | 諡…… | 門人私諡貞文先生 (Lin Shu) |
| works | 著有…… / 有……等 | 著有《文集》…… |

**Names.** A man of letters had several names, used in different settings:

| Term | Meaning | Use |
|---|---|---|
| 名 | given name | used by himself and his superiors; in a biography, after the first mention |
| 初名 | original given name | if he changed it |
| 字 | courtesy name, taken at adulthood | used by friends and equals |
| 號 | style, sobriquet (often literary) | 林紓，字琴南，號畏廬 |
| 諡 | posthumous name, granted by the court (or 私諡 by disciples) | 諡文直 |

After the first mention the biography uses the given name alone: 復, 紓. Readers of letters and
essays must also recognise the 字 and 號: Yan Fu is 又陵 or 幾道, Lin Shu 琴南 or 畏廬. Indexes
of names and courtesy names (室名別號索引) help. See [Names, titles and offices](../toolkit/t03-names-titles-offices.md).

**Age.** 年六十有九 "aged sixty-nine": 有 joins the tens and the units. Ages are
counted in *sui* 歲: one at birth, one more each new year. Subtract one or two to get the age in
Western years.

**Career verbs.** Appointments have their own verbs, each with a nuance:

| Verb | Meaning |
|---|---|
| 授 | to be appointed (to a first or new post) |
| 遷 | to be transferred (usually promoted) |
| 擢 | to be promoted (often out of turn) |
| 署 | to act in a post |
| 充 | to serve as (a commission) |
| 尋 | soon afterwards |
| 累保 | to be recommended repeatedly (and so rise) |

**The biographer's judgement.** A biography is not a neutral record. What it chooses to quote,
what it omits and what it praises (忠, 孝, 氣節) show the compilers' values. Compare it with
other sources before you trust it.
