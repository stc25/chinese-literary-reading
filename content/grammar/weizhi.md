## Summary

X謂之Y means "X is called Y"; often a description comes first and 謂之 introduces the name at the end.

## Explanation

謂 means "to call, to name", and 之 is the object pronoun "it" (see
[之 as object pronoun](zhi-object.md)). Together, 謂之 Y is "(one) calls it Y".

The pattern usually runs:

> description，謂之 name。

- 地球行至日與月相對之間，則地掩蔽日光，不能映射月面，謂之月蝕 "when the earth moves
  between the sun and the moon … this is called a lunar eclipse".

Here 之 refers back to **everything described** before it, not to a single word. In
English it often reads better to start with the name: "A lunar eclipse is when…".

**Compare 曰.** 曰 can also introduce a name after a description (日月隱蔽曰蝕), but it
does not contain a pronoun. 謂之 usually follows a longer description and stands after a comma. See
[曰: "is called", "namely"](yue-naming.md).

**謂 + object + 為/曰.** You will also meet 謂 X 為 Y "call X Y", where the thing named
comes between 謂 and the name.
