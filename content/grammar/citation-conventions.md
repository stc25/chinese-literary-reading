## Summary

How scholars quote sources, mark variant readings and add their own comments.

## Explanation

**Introducing a quotation.** A quotation is introduced by a verb of saying after the source:

| Formula | Meaning | Example |
|---|---|---|
| 某曰 | X says | 司馬遷曰 |
| 某云 | X says (often for books) | 《輿地紀勝》云 |
| 某之說曰 | the account of X says | 《春秋左氏傳》之說曰 |
| 其《書》有曰 | in his *Book* he says | 其《天演論・自序》有曰 |
| 某稱 | X states | 《孟子》稱 |
| 某詩云 | X's poem says | 任逢詩云 |
| 見某 | see X, it is found in X | 有記見文 |

Book titles are often abbreviated: 《史》 for 《史記》, 《漢》 for 《漢書》, 《通志》 for the provincial
gazetteer. Sources are often given as "author + title" without a verb at the end of an entry
(張乃孚《合州志》), meaning "from X".

**Where a quotation ends.** Older texts have no quotation marks. A quotation ends where the
next citation begins, where a comment such as 此……也 or 案 starts, or where the subject
changes. Modern editions supply 「」, and editors disagree. When you cite a text, check where
your edition closes the quotation.

**Quotations within quotations.** Modern punctuation uses 「」 outside and 『』 inside:
其《天演論・自序》有曰：「……司馬遷曰：『……』……」.

**Referring back.** 所謂……者 "what is called …" picks up a phrase already quoted or well known
and makes it the topic of a new sentence: 遷所謂『本隱之顯』者外籀也. 云者 does the same after a
term: 內籀云者 "what is called induction".

**The scholar's comment.** A comment is marked off from the source:

| Marker | Meaning |
|---|---|
| 案 / 按 àn | "note", the compiler's or commentator's comment |
| 某案 / 某按 | X's note (森楷案, 復案) |
| 坿記 / 附記 | appended note |
| 自記 | the author's own note |
| 注 / 註 | commentary (on a classic) |
| 疏 | sub-commentary (on the commentary) |
| 某某注 | X's commentary: 鄭康成《喪服小記》注 |

**Variant readings and corrections.** Textual critics have a compact vocabulary:

| Word | Meaning | Example |
|---|---|---|
| 作 | (a text) reads, has | 《通志》作二十里 "the *Provincial Gazetteer* has 'twenty li'" |
| 一作 | another text has | |
| 誤 / 譌 / 訛 | wrong, a corruption | |
| 當作 | should read | |
| 今删 / 今改正 / 今訂正 | now deleted / corrected | 今删二字 |
| 疑 | (I) suspect | |
| 衍 | superfluous (character) | |
| 脫 | missing (character) | |

**Weighing sources.** A scholar of the 1910s quotes his sources and then judges them: 此二說中，
後說尤爲詳密，顧皆後儒充類之說 "of these two accounts, the latter is more detailed, but both are
the extrapolations of later Confucians". Notice the order: quote, compare, criticise, keep what
is valid.
