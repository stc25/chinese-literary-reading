## Summary

Wade–Giles, postal and other period spellings, and how to convert them to pinyin.

## Wade–Giles

Most Western scholarship before the 1980s, and many library catalogues until 2000, spell Chinese in
**Wade–Giles**, devised by Thomas Wade (1867) and revised by Herbert Giles (1892). Its main features:

- **Aspiration** is marked with an apostrophe: p / p' = pinyin b / p; t / t' = d / t; k / k' = g / k;
  ch / ch' = zh or j / ch or q; ts / ts' = z / c. The apostrophe is often dropped in print, which makes
  Chang ambiguous (Zhang or Chang).
- **Tones** are marked with superscript numbers (ma³), but usually left out.
- Syllables of a given name are joined with a hyphen: Liang Ch'i-ch'ao.

## Postal spellings

Place names often appear in the **postal system** (1906), based on older customary spellings and often on
southern pronunciations. It is not a system, so learn the common ones.

## Other spellings

- **Personal names** often follow the bearer's own usage or a dialect: Sun Yat-sen (Cantonese, 孫逸仙),
  Chiang Kai-shek (Cantonese, 蔣介石), T. V. Soong (宋子文), Wellington Koo (顧維鈞).
- **French School** (École française d'Extrême-Orient) and **German** systems appear in older European
  scholarship: French tch = zh, German tsch = ch.
- **Yale** and **Gwoyeu Romatzyh** (國語羅馬字, 1928, which marks tones by spelling) are rarely met outside
  textbooks.
- **Japanese readings** are used in some Western works for Chinese titles printed in Japan.

## Conversion table

Initials and finals where Wade–Giles differs from pinyin:

| Wade–Giles | Pinyin | Example |
|---|---|---|
| p, p' | b, p | Pao → Bao; P'eng → Peng |
| t, t' | d, t | Tao → Dao; T'ang → Tang |
| k, k' | g, k | Kuang → Guang; K'ang → Kang |
| ch, ch' (before a, e, o, u) | zh, ch | Chang → Zhang; Ch'en → Chen |
| ch, ch' (before i, ü) | j, q | Chiang → Jiang; Ch'ing → Qing |
| hs | x | Hsü → Xu; Hsüeh → Xue |
| ts, tz; ts', tz' | z; c | Tseng → Zeng; Ts'ai → Cai; Tzu → Zi |
| ss, sz | s | Ssu-ma → Sima; Szechwan → Sichuan |
| j | r | Jen → Ren; Juan → Ruan |
| -ih (after ch, sh, j) | -i | Chih → Zhi; Shih → Shi |
| -ŭ, -u (after tz, ss) | -i | Tzŭ → Zi; Ssŭ → Si |
| -ien | -ian | Lien → Lian; Tien → Dian |
| -ung | -ong | Kung → Gong; Chung → Zhong |
| -o (after k, h) | -e | Ko → Ge; Ho → He |
| -eh | -e | Yeh → Ye; Hsieh → Xie |
| yu | you | Yu → You (but Yü → Yu) |
| -uei | -ui | Kuei → Gui |

Worked examples: Tseng Kuo-fan = Zeng Guofan; Li Hung-chang = Li Hongzhang; Yüan Shih-k'ai = Yuan Shikai;
K'ang Yu-wei = Kang Youwei; Liang Ch'i-ch'ao = Liang Qichao; Yen Fu = Yan Fu; Chang Ping-lin = Zhang
Binglin; Ts'ai Yüan-p'ei = Cai Yuanpei.
